# Выезд — демо системы для выездных мастеров

Демо для компаний, которые продают, устанавливают и обслуживают газовые котлы
(и вообще для любых компаний с мастерами «на выезд»).
Регион: Бишкек и пригороды: Кант, Сокулук, Лебединовка, Новопокровка, Токмок, Кара-Балта и др.

Сейчас заявки раздают через WhatsApp. Демо показывает, как это может выглядеть иначе:

| Роль | Что видит |
|---|---|
| **Диспетчер** (`#/dispatcher`) | Все заявки и мастера на карте. Подбор ближайшего свободного мастера, маршрут, оптимизация порядка объезда на день, журнал событий |
| **Мастер** (`#/master`) | Мобильное приложение: заявки на день, кнопка «Маршрут в 2ГИС», статусы «Выехал / На месте / Завершить», отчёт с фото |
| **Владелец** (`#/owner`) | Выручка, заявки по дням, время на объекте, опоздания, повторные выезды по каждому мастеру и автоматические подсказки |
| **Режим для показа** (`#/demo`) | Диспетчер и телефон мастера на одном экране — для видео и живых встреч |

Все данные вымышленные: генерируются при первом открытии (месяц истории + текущий день).
Изменения хранятся в `localStorage` браузера. Открой диспетчера и мастера в двух
вкладках — они синхронизируются. Сбросить данные можно в «Настройках».

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
```

```bash
npm run dev
```

Откроется на http://localhost:5173. Чтобы открыть с телефона в той же Wi-Fi сети,
используй адрес `Network`, который покажет Vite.

## Ключ 2ГИС (настоящие маршруты)

Без ключа всё работает, но маршруты строятся приблизительно (пунктир по прямой,
время оценивается по средней скорости). С ключом маршруты идут по дорогам
с учётом пробок через Routing API 2ГИС.

1. Получи демо-ключ: https://platform.2gis.ru/ru/keys/create/demo
2. Вставь его одним из способов:
   - **на сервере (рекомендуется):** переменная окружения `DGIS_KEY`. Локально — файл `.env`
     (скопируй `.env.example`), на Vercel — Settings → Environment Variables.
     Ключ не попадает в браузер.
   - **в самом демо:** «Настройки» → «Ключ API 2ГИС». Хранится только в этом браузере.
3. Бейдж в шапке сменится на «Маршруты: 2ГИС».

> Формат Routing API собран по документации 2ГИС (`routing/7.0.0/global`).
> Если 2ГИС ответит ошибкой, демо само перейдёт на приблизительные маршруты,
> а причина будет в консоли браузера и во всплывающей подсказке бейджа.

Карта — растровые тайлы 2ГИС через Leaflet. Если они не грузятся,
автоматически включается OpenStreetMap.

## Выложить в интернет (Vercel, бесплатно)

1. Зайди на https://vercel.com и войди через GitHub.
2. **Add New → Project** → выбери этот репозиторий.
   Vercel сам определит Vite, ничего менять не нужно.
3. В **Environment Variables** добавь `DGIS_KEY` = твой ключ 2ГИС.
4. **Deploy**. Через минуту будет ссылка вида `https://<имя>.vercel.app`.

Дальше каждый `git push` обновляет сайт автоматически. Свой домен подключается
в Settings → Domains.

Серверная функция `api/route.js` проксирует запросы к 2ГИС, поэтому ключ не виден
посетителям сайта.

## Сценарий видео (1–2 минуты)

Открой `#/demo` в полноэкранном браузере и включи запись экрана.

1. **Проблема (10 с).** «Сейчас заявки раздаются в WhatsApp. Непонятно, кто где,
   кто ближе и кто сколько сделал».
2. **Входящая заявка (15 с).** Нажми «Входящая из WhatsApp». Заявка появляется
   на карте, система предлагает ближайшего мастера со временем в пути.
3. **Назначение (15 с).** «Назначить» — справа в телефоне мастера заявка появляется
   сразу. (Выбери этого мастера в списке над телефоном.)
4. **Выезд (20 с).** В телефоне «Выехал». На карте мастер едет по маршруту,
   клиенту уходит уведомление «Мастер выехал, будет через N мин» (видно в «Журнале»).
5. **Отчёт (15 с).** «На месте» → «Завершить заявку» → отметить работы, сумму → «Закрыть».
6. **Маршрут дня (15 с).** Вкладка «Мастера» → Сергей Ким → «Оптимизировать порядок
   объезда»: видно, сколько км экономится.
7. **Владелец (20 с).** Вкладка «Владелец»: выручка, заявки по дням, таблица мастеров
   и подсказки «на что обратить внимание».

## Структура

```
api/route.js          Vercel-функция: прокси к Routing API 2ГИС
api/_handler.js       логика прокси (общая для Vercel и dev-сервера)
shared/dgis.js        запрос и разбор ответа Routing API
src/config.js         районы, типы работ, мастера, цвета статусов
src/data/seed.js      генерация демо-данных
src/store.js          состояние, действия, синхронизация вкладок
src/routing.js        построение маршрутов: сервер → 2ГИС напрямую → оценка
src/geo.js            расстояния, движение по маршруту, оптимизация объезда
src/views/            экраны: Dispatcher, Master, Owner
```
